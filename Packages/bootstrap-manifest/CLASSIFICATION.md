# Bootstrap package classification — CustomDopamine (iPhone 7 Plus / A10 / iOS 15.8.5)

Source of the 68-package base set: `Procursus/Makefile`, `bootstrap::` target (see Phase 1 analysis, §4). This is *already* the minimal set Procursus itself ships as "the bootstrap" — it is not "everything in Sileo," so almost all of it is KEEP by default. The table below calls out the handful that are genuinely optional or need runtime verification on your device rather than pretending every line needs individual justification it doesn't have.

## What I actually changed in this fork so far (this session)
- Dropped the `arm64e` compile slice from every BaseBin subproject that built one (`launchdhook`, `systemhook`, `boomerang`, `libjailbreak`, `jbctl`, `hookd`, `watchdoghook`, `rootlesshooks`) — arm64-only build now, since A10 has no arm64e mode.
- Trimmed `dyldhook`'s Makefile from 6 build variants down to the single `arm64.iOS15` one you need.
- **Removed `forkfix` entirely** (subproject dir + all `BaseBin/Makefile` references + the call site in `systemhook/src/main.c`). Confirmed via source, not guessed: the call site was wrapped in `#ifdef __arm64e__` — it existed only to work around a PAC-era fork-after-page-patch issue, so it's fully dead on plain arm64.
- Removed `zebra.deb` and its `PkgManagers.plist` entry (redundant second package manager).
- Left `sileo.deb`/its plist entry in place *for now*, as a bridge — see the comment left in `PkgManagers.plist`. Replacing it with your own merged package-manager screen is Application/Xcode-project work I haven't touched yet (see next steps).
